# Публикация ClearCount на GitHub с автообновлением (без Терминала, ~15 минут)

После этих шагов сайт будет по адресу `https://ВАШ-ЛОГИН.github.io/clearcount/`. Каждую ночь он сам скачивает свежие данные NASA и пересчитывается.

## Шаг 1. Аккаунт
1. Откройте https://github.com/signup и зарегистрируйтесь. Подтвердите почту.

## Шаг 2. Репозиторий
1. Нажмите **+** справа вверху → **New repository**.
2. **Repository name:** `clearcount`.
3. Выберите **Public**. Это обязательно: Space Apps требует ссылку, открытую без логина.
4. Нажмите **Create repository**.

## Шаг 3. Загрузите файлы (перетаскиванием)
1. На странице репозитория нажмите ссылку **uploading an existing file**.
2. Откройте в Finder папку **`Desktop → space → clearcount_repo`**.
3. В Finder нажмите **Cmd + Shift + .** (точка). Так станут видны скрытые папки, включая `.github` — без неё автообновление не заработает.
4. Выделите **всё** внутри `clearcount_repo` (Cmd + A) и перетащите в окно браузера.
5. Внизу нажмите **Commit changes**.

> Проверка: в репозитории должна появиться папка `.github/workflows` с файлом `update.yml`.
> Если её нет, создайте файл вручную:
> 1. **Add file → Create new file**.
> 2. В имени файла напишите `.github/workflows/update.yml`.
> 3. Вставьте содержимое файла `clearcount_repo/.github/workflows/update.yml` и сохраните.

## Шаг 4. Секреты (ключи видны только GitHub)
1. Откройте **Settings → Secrets and variables → Actions → New repository secret**.
2. Добавьте три секрета:

| Name | Значение |
|---|---|
| `FIRMS_MAP_KEY` | ваш ключ FIRMS из письма (32 символа) |
| `EARTHDATA_USERNAME` | `dariyaanu` |
| `EARTHDATA_PASSWORD` | ваш пароль Earthdata |

Секреты зашифрованы: их не видит никто, включая Claude, и они не попадают в код или на сайт.

## Шаг 5. Включите сайт
1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment → Source** выберите **GitHub Actions**.

## Шаг 6. Первый запуск
1. Откройте вкладку **Actions**. Если GitHub спросит, разрешите workflows.
2. Слева выберите **Update ClearCount data**, нажмите **Run workflow**, в поле *mode* напишите `full` и снова нажмите **Run workflow**.
3. Первый полный расчёт займёт около 1–2 часов. Дальше всё идёт само:

| Когда | Что обновляется |
|---|---|
| каждую ночь | новые точки пожаров |
| по понедельникам | облака, погода, тренды, ML |
| 1-го числа каждого месяца | продукты Earthdata |

4. Когда появится зелёная галочка, сайт будет готов: ссылка видна в **Settings → Pages**.

## Если что-то пошло не так
- Красный крестик в Actions: откройте запуск, скопируйте последние строки ошибки и пришлите Claude.
- Если какой-то сервис NASA временно недоступен, этот шаг пропускается. Сайт остаётся с последними удачными данными и не ломается.
- На сайте наверху видно: «⟳ updated …», то есть когда был последний пересчёт.
