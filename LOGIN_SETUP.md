# Регистрация и ключи — делаете вы, пароли никому не отправляете

Пароль **не нужно** присылать в чат, и Claude его не видит. Команды ниже спрашивают пароль скрытно, без отображения на экране, и сохраняют его только на вашем компьютере. Скрипты ClearCount потом читают его из файла.

## 1. NASA Earthdata Login (бесплатно, ~3 минуты)
Что он открывает:
- точные маски облачности и огня MYD14A1, MOD14A1, VNP14A1 и VJ114A1: «было ясно / было облако» над пожаром, по дням;
- карту типов земли MCD12Q1, чтобы разделить календарь на лес, степь и поля;
- площади гарей MCD64A1 — независимую проверку согласованного ряда.

Шаги:
1. Откройте https://urs.earthdata.nasa.gov/users/new и зарегистрируйтесь. Подтвердите почту.
2. Откройте **Терминал** на Mac и вставьте эту команду. Она спросит логин и пароль; пароль при вводе не отображается.
```bash
read -p "Earthdata username: " U; read -s -p "Earthdata password: " P; echo; printf "machine urs.earthdata.nasa.gov login %s password %s\n" "$U" "$P" >> ~/.netrc; chmod 600 ~/.netrc; unset P; echo "saved"
```
Это стандартный способ, который рекомендует NASA: файл `~/.netrc` доступен только вашей учётной записи на этом компьютере.

## 2. FIRMS MAP_KEY (бесплатно, ~1 минута)
Что он открывает:
- данные за 2026 год, включая текущий месяц, так что карточка «Сейчас» станет действительно сейчас;
- спутник NOAA-21.

Шаги:
1. Откройте https://firms.modaps.eosdis.nasa.gov/api/map_key/, введите почту и получите ключ в письме.
2. В Терминале выполните команду и вставьте ключ, когда она попросит:
```bash
read -s -p "FIRMS MAP_KEY: " K; echo; echo "FIRMS_MAP_KEY=$K" > ~/Desktop/space/clearcount/.env; chmod 600 ~/Desktop/space/clearcount/.env; unset K; echo "saved"
```
Файл `.env` добавлен в `.gitignore` и никуда не попадёт.

## 3. Напишите Claude «готово»
После этого Claude запустит:
- `11_firms_api.py`: 2026 год и NOAA-21;
- `12_earthdata.py landcover | cases | burned`: типы земли, точные маски для кейсов, проверка по площадям гарей;

затем пересчитает весь пайплайн.

## Ресурсы не из интернета (тоже очень сильно повышают балл)
| Что | Зачем | Кто делает |
|---|---|---|
| Короткий звонок или письмо в **ДЧС области** (Абай, Павлодар) или в **Казгидромет** | Цитата живого пользователя: «нам это нужно, потому что…» → критерий **Impact** | команда |
| Запрос **официальной статистики пожаров** по годам (МЧС, Комитет лесного хозяйства) | Заполнить столбец «Зарегистрировано» и сравнить с обнаруженным | команда |
| **Носитель казахского** проверяет тексты интерфейса | Чистый KZ-интерфейс | команда |
| Запись **видео до 30 секунд** (EN или с английскими субтитрами) | Обязательно для глобального судейства | команда + Claude (сценарий) |
